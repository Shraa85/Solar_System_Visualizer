# 🌌 Solar System Visualizer

An interactive **full-stack web application** that enables users to explore the Solar System through detailed planetary information, engaging visualizations, and an interactive quiz. Built using **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**, the project combines education with an intuitive user experience.

---

## 🚀 Features

- 🔐 Secure user registration and login
- 🌍 Explore detailed information about all major planets
- 🪐 Interactive Solar System visualization
- 📝 Quiz module to test knowledge of the Solar System
- 📱 Responsive and user-friendly interface
- 💾 SQLite database for user and application data
- ⚡ Flask-powered backend with dynamic content rendering

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Shraa85/Solar_System_Visualizer.git
```

Move into the project directory:

```bash
cd Solar_System_Visualizer
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
